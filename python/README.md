## Python LAB-001 — Boolean Access Decision

**Status:** learning exercise; code staged in this repository for review. The student previously ran the same Boolean logic locally with `True` and `False` outcomes on 2026-10-14. This branch copy has **not** been independently executed on the student's notebook.

Run in PyCharm or in a terminal:

```bash
python python/lab001_acesso.py
```

The default values print `True`, because the account is active and a special authorization is present even though payment is overdue.

Change `autorizacao_especial = False` while leaving `mensalidade_em_dia = False`. The expected result becomes `False`.

**Learning objectives:** variables, Boolean values, `and`, `or`, parentheses, and `print()`.

**What this is not:** a working access-control system, facial recognition, login, IAM implementation or connection to physical equipment.
